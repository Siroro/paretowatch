# ParetoWatch v0.12.0

## Highlights

- Added all-time price-floor alerts for models that reach a new low.
- Added discount and seller-health alert rules with configurable thresholds.
- Added minimum-percentage and direction filters for price-change alerts to reduce noise.
- Added feed-wide alerts when models are newly listed or delisted.
- Added wildcard Pareto frontier entry and exit watches across the selected benchmark view.
- Unified desktop notifications with an in-app notification history and clearer alert summaries.
- Integrated notification events with history and refreshed alert settings/status presentation.

## Validation

The v0.12.0 alert and notification changes are validated with the repository's formatting, locked check, locked test, Clippy, and locked build commands. GitHub release packages are produced for Windows and Linux by the `v0.12.0` tag workflow.
